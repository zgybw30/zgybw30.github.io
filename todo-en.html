ABOUT

About ShiguangTodo

ShiguangTodo is a Windows desktop to-do widget: a frameless rounded window you park in a corner of your desktop — pin it, make it translucent, resize it as you like. It never steals focus, shows no ads, and quietly helps you finish today, one task at a time.

Built from scratch with Qt 6 (QML + C++), everything runs locally: no account, no cloud sync — your to-do data lives in the data/ folder on your own computer.

  • Frameless widget: drag, resize, pin, transparency
  • Natural-language date parsing in Chinese
  • Reminder bar, tray notifications and snooze
  • Local storage with one-click zip backup

System requirements

To run it: just Windows 10 / 11. It's light on memory and happy on older PCs.

To build it yourself: Qt 6.12 + MSVC2022. The build script configures the environment automatically — see the repo README.

Three steps to using it

1

Get the source

Download or clone the repo from GitHub (Clone or download → Download ZIP works).

2

Double-click to build

Run build.bat — the script sets up the Qt and compiler environment and produces ShiguangTodo.exe.

3

Start using it

Launch the exe, park the widget in a corner, and write down today's first task.

Your to-do data lives in the data/ folder next to the exe — copy the whole folder to back it up.

FAQ

Questions

Is it free?

Yes — free, with every feature open. No in-app purchases, no subscription.

Where does my data live?

In the data/ folder next to the exe (data.json + images/). Nothing uploads anywhere. One-click zip backup in Settings; copy data/ to move to another PC.

Which systems are supported?

Windows 10 / 11 desktop. macOS and Linux are not planned.

Do reminders work in the background?

Yes. Close the main window and the app stays in the tray, popping a reminder bar and system notification on time. Snooze when you're busy.

Can it start with Windows?

Yes — turn on autostart in Settings. A global hotkey and voice input are also available (Windows).
