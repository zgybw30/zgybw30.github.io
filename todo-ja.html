ABOUT

拾光待辦について

拾光待辦は Windows のデスクトップ ToDo ウィジェットです。枠のない角丸の小窓をデスクトップの隅に置いて、固定・半透明・リサイズは自由自在。フォーカスを奪わず、広告も出さず、今日のタスクを一つずつ片付ける手伝いだけをします。

Qt 6（QML + C++）で一から実装し、すべての機能はローカルで動作します。アカウントもクラウド同期もなく、ToDo データは自分の PC の data/ フォルダの中にだけあります。

  • 枠なしウィジェット：ドラッグ / リサイズ / 固定 / 透明度
  • 中国語の自然言語で日時を認識
  • リマインダーバー + トレイ通知 + スヌーズ
  • ローカル保存、ワンクリック zip バックアップ

動作環境

実行に必要なのは Windows 10 / 11 のみ。メモリ使用量も少なく、古い PC でも快適に動きます。

自分でビルドする場合は Qt 6.12 + MSVC2022 が必要です。ビルドスクリプトが環境を自動で設定します。詳しくはリポジトリの README をご覧ください。

3ステップで使い始める

1

ソースを取得

GitHub からリポジトリをダウンロードまたはクローンします（Clone or download → Download ZIP で十分です）。

2

ダブルクリックでビルド

build.bat を実行すると、スクリプトが Qt とコンパイラ環境を自動で設定し、ShiguangTodo.exe を生成します。

3

使い始める

exe を起動し、ウィジェットをデスクトップの隅に置いて、今日の最初のタスクを書き込みます。

ToDo データは exe の横の data/ フォルダにあります。バックアップは data/ フォルダごとコピーするだけです。

FAQ

よくある質問

無料ですか？

はい、無料で全機能をご利用いただけます。アプリ内課金もサブスクリプションもありません。

ToDo データはどこに保存されますか？

exe の横の data/ フォルダ（data.json + images/）に保存され、どこにもアップロードされません。設定からワンクリックで zip バックアップができ、PC 移行は data/ をコピーするだけです。

対応 OS は？

Windows 10 / 11 のデスクトップです。macOS と Linux の予定はありません。

バックグラウンドでも通知は届きますか？

はい。メインウィンドウを閉じてもトレイに常駐し、時間になればリマインダーバーとシステム通知を表示します。忙しいときはスヌーズできます。

Windows 起動時に自動起動できますか？

はい、設定から自動起動を有効にできます。グローバルホットキーでの呼び出しと音声入力にも対応しています（Windows）。
