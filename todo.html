ABOUT

关于拾光待办

拾光待办是一个 Windows 桌面待办小部件：无边框圆角小窗，拖到桌面一角，置顶、半透明、缩放都随你。它不抢焦点、不弹广告，只安静地帮你把今天的事一件件做完。

用 Qt 6（QML + C++）从零实现，全部功能本地运行：没有账号，没有云同步，待办数据只存在你电脑上的 data/ 目录里。

  • 无边框小部件：拖拽 / 缩放 / 置顶 / 透明度
  • 中文自然语言识别时间
  • 提醒条 + 托盘通知 + 贪睡
  • 数据本地存储，一键 zip 备份

FAQ

常见问题

免费吗？

免费，全部功能免费使用，没有内购，没有订阅。

我的待办数据存在哪？

exe 旁边的 data/ 目录（data.json + images/），不上传任何服务器。设置里可以一键 zip 备份，换电脑把 data/ 拷走就行。

支持哪些系统？

Windows 10 / 11 桌面端。macOS 与 Linux 暂无计划。

提醒在后台也能收到吗？

可以。关掉主窗口后程序留在托盘，到点弹出提醒条与系统通知；正忙着可以贪睡，稍后再提醒。

能开机自启吗？

可以，在设置里打开自启即可；还支持全局热键呼出与语音输入（Windows）。
